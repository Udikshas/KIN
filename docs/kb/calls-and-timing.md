# Calls and timing

## When Kin calls
Kin calls at a time the family chooses, usually in the evening. If the parent is busy, they can ask Kin to call later.

## How long a call lasts
A call is planned for one, three or five minutes. A daily call is about three minutes. The parent can end the call any time by saying bye.

## Missed calls
If the parent does not answer, Kin tries again a little later. If several calls in a row go unanswered, the family is told.
